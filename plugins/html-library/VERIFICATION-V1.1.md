### 故障定位与修复

真实界面使用了新客户端和旧宿主模块：展开目录后没有文件节点，浏览器操作报 HTTP 404。

没有重启整个 DSH，也没有修改用户 HTML 文件。

额外调整：去掉重复模式栏；浏览页不再出现无必要的“阅读”开关；管理目录入口改用明确文案。
列表增加标题宽度并允许两行，摘要优先提取正文段落并跳过生成器署名。
客户端兼容旧快照格式，可补查文档构建树，避免前后端混用时静默显示空目录。
