# HTML Library（规划中）

目标：在 DSH 中集中管理和阅读本地 HTML 知识页面，不必散落在目录中、反复通过浏览器双击打开。

## 产品方向

- 浏览、管理本地 HTML 文件，方便快速查找与打开。
- 保留浏览器原生 HTML 渲染及原有 CSS、布局、图表效果，不强制转 Markdown。
- 处理内联/外部 CSS、图片、字体和相对路径资源。
- 加载失败不能只显示空白，应说明原因并提供「在浏览器打开」入口。
- 阅读优先、内容优先，减少无用侧栏、解释文本和视觉干扰。

## 仍需确认

- DSH 实际插件接口、页面嵌入与本地文件访问权限。
- CSP、沙箱隔离、资源路径和安全策略。
- 文件索引、刷新、导入及数据持久化行为。

当前是需求入口，并非完整需求文档或可安装插件。开发前依照 [开发规范](../../docs/DEVELOPMENT.md) 补齐详细需求与验收用例。
