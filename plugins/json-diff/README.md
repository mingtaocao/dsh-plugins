# 文件对比

从 DSH 侧栏打开「文件对比」，左栏粘贴原文，右栏粘贴新版。编辑时自动按行比较，保留空格、缩进、空行和标点。仅一侧有内容时，对侧按空文本处理。换行符统一后再比较。

差异直接在编辑区标出。原文使用浅红底，新版使用浅绿底，行内变化范围进一步加深。右上角统计新增、删除和修改的行数。两栏行号旁会标出变化行。点击右侧差异位置图、上一处或下一处可定位变化行，底部同步展开该行的原文和新版。展开「全部差异」可从列表跳转。两份内容一致时仅显示提示。

拖动中线调整两栏宽度，双击恢复等宽，也可以聚焦分隔线后用左右方向键微调。每侧最多支持 50 万字符、5000 行，大段无共同内容时会提示分段。

## 安装

在仓库根目录运行 `dsh plugin --profile desktop add ./plugins/json-diff`，重新打开桌面工作区。Web 版使用 `--profile web`。比较在本地完成，粘贴内容只保存在面板内存中。

在插件目录运行 `npm test` 验证比较逻辑。卸载桌面版插件可运行 `dsh plugin --profile desktop remove dsh-json-diff`。
