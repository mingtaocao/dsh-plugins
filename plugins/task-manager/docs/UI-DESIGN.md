## 设计与实现

- 导航：左侧上方是列表、看板、四象限入口，下方以分隔线区分项目列表。顶部不再重复视图切换，只显示当前视图标题与「…」菜单，导入导出收进菜单。切换视图不改变项目范围或状态筛选。
- 列表：标题和完成控件放左侧，辅助信息放右侧；子任务缩进展开。
- 看板：浅层背景区分列，数量用小徽标；项目栏缩至 176px，各列最小宽度改为 170px。
- 卡片：轻边框、紧凑间距，标题优先；项目、日期和非普通优先级按需展示。
- 分类：默认待办、Q4 不常驻标签，看板不重复列状态，矩阵不重复列象限。非默认分类可显示轻量标签；菜单始终提供状态与象限选择器，保留原生 select 的键盘操作。
- 菜单：悬停或键盘聚焦显示「…」，触屏常显。原生 Popover 放在顶层，避免被列滚动裁切；提供详情和上移/下移。
- 子任务：辅助信息行只显示一处 N/M；保留展开、独立完成和菜单排序。
- 主题：沿用宿主颜色变量，补充深色状态标签；尊重减少动画偏好。

## 完成排序、项目收纳与子任务交互

2026-11-14：列表及父任务内部的子任务先显示未完成项，保留手动顺序；已完成项按完成时间从早到晚沉底。列表与详情显示本地完成时间，估算时间明确标注；取消后清空，再完成记录新时间，普通编辑不刷新。列表的已完成项不允许手动排序，拖动未完成项到完成区边界会追加到未完成区末尾。

全部任务按项目呈现文件夹，默认折叠，独立展开。左侧「列表」改为「全部任务」，点击后回到跨项目总览；具体项目入口直接打开项目任务。看板、四象限保留视图功能。

再次在本机 Super Productivity 核对：主任务右键菜单的「添加子任务」打开行内输入。按此方式增加主任务菜单入口，回车创建、Esc 关闭输入。子任务创建后直接显示在列表里，缩进展示，标明所属主任务并支持点回主任务；保留手动折叠和详情创建入口，仍只允许两级。

验证：29 个核心测试通过。真实 DSH 0.2.2-rc.2 独立 Profile 实测 B/A 依次完成后的 C/B/A 顺序，B 取消再完成后为 C/A/B；普通编辑和浏览器刷新保留完成时间。未完成任务的菜单排序、拖到完成边界，以及子任务完成后沉底且不改变父任务完成时间均通过。

项目文件夹的默认折叠、键盘展开、嵌套子任务不误关项目、视图切换保留展开状态、状态筛选和单项目直达均已验证。最新交互验证通过：菜单创建子任务、立即可见、父任务归属链接、Esc 退出输入、父子独立完成，以及「全部任务」返回项目总览。浏览器控制台无错误或警告。
