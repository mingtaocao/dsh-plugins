# Super Productivity 界面与操作对照修正

2026-11-15。基于用户提供的截图与本机安装的 Super Productivity 20.0.0。只读提取已安装应用的 Web renderer 到临时目录，在独立浏览器来源中实际操作快速添加、任务右键菜单、子任务输入和详情面板；没有访问 SP 的日常任务数据，也没有将 SP 的脚本、样式或字体复制进插件。

范围是已有项目、任务、子任务、列表、看板、四象限和导入导出体验。继续遵循 REQUIREMENTS.md：不新增今日计划、Inbox、计时、标签、附件或多层项目文件夹数据模型；也不宣称像素一致或完整 SP 功能兼容。

## 逐项差异与修正

| 项目 | 原有差异 | 本轮实现 |
|---|---|---|
| 工作区标题 | 任务区上方重复显示项目名，顶栏横跨整个插件 | 只有一个工作区标题，与项目菜单、添加和筛选按钮放在主区域顶栏 |
| 快速添加 | 表单、项目选择和提交按钮一直占据空间 | 顶部「＋」按需展开；Shift+A 打开，Enter 连续创建，Esc 收起；跨项目创建仍需明确选择项目 |
| 筛选与搜索 | 状态与刷新一直铺在录入栏，没有搜索 | 筛选按钮展开搜索、状态和矩阵完成开关；搜索覆盖标题、描述、备注与子任务，并保留主任务上下文；隐藏筛选时仍显示启用提示，可清除 |
| 左侧导航 | 仅目录分组能折叠，缺少紧凑导航和直接新增入口 | 保留独立目录折叠并新增图标紧凑模式；项目旁「＋」可直接新增，成功后进入项目并聚焦任务输入；显示未完成主任务数 |
| 任务行层级 | 选中反馈弱，项目/日期/标签挤在右侧，小字较难辨认 | 蓝色选中边框与浅色背景，元信息放在标题下方；父子标题同为 14px、勾选框同为 16px；增加备注图标和逾期日期颜色 |
| 任务操作 | 只有主任务「…」入口，子任务缺少相同菜单 | 主、子任务均支持右键和 Shift+F10 打开各自菜单；提供详情、状态、排序和删除，主任务另有添加子任务，删除继续二次确认 |
| 完成列表 | 已完成项沉底但没有明确分界 | 底部增加可用鼠标和键盘折叠的「已完成」分组，保留完成时间排序及父子独立状态 |
| 详情结构 | 长表单、显式保存、上下翻找 | 标题直接编辑；子任务、属性、日期、象限、描述、备注分块；部分默认折叠；备注区保持展开，面板显示保存状态和创建时间 |
| 编辑可靠性 | 加子任务会使未保存的父任务版本过期；切换宿主面板丢草稿 | 受控字段草稿，600ms 防抖和失焦保存；导航、关联操作和读取导出前先保存；请求串行，字段级提交；冲突保留输入，草稿按任务 ID 存浏览器本地，重开可恢复，成功后清理 |
| 紧凑尺寸与主题 | 窄卡片被多个图标挤成逐字换行；深色和详情覆盖层需要复核 | 对主任务区与卡片分别使用命名容器查询；窄卡片简化进度与备注常驻图标、缩短子任务缩进，完整操作保留在菜单；沿用宿主亮暗表面并使用蓝色强调色 |

## 编辑策略

只把实际编辑的字段提交给 Host。保存请求未完成时继续输入，会保留并随后提交新的文本，不用旧响应覆盖新输入。关联任务操作先等待当前草稿保存，再以最新快照版本提交。

真正的外部版本冲突仍会报告错误，不会伪装成功；草稿继续留在输入框和浏览器本地，重试只提交编辑字段。已验证其他来源修改优先级后，本地备注冲突、恢复再保存，不会把优先级写回旧值。离开宿主面板时即使保存失败，下次打开该任务仍能恢复本地草稿。本地草稿不是备份或云同步，清除浏览器数据会清除尚未落盘的草稿。

## 实际验证

独立临时 DSH_HOME，DSH 0.2.2-rc.2、Node 24.15.0、Chrome；窗口 1280×720 和 900×720。未读写用户日常任务库。

- `npm run check` 通过，两个新增浏览器脚本的 `node --check` 通过。
- `npm test`：29 个核心用例通过。
- 全新浏览器会话运行 `tests/ui-workflows.playwright.js` 通过：项目创建直达、回车连续录入、添加子任务前保存、延迟保存期间继续编辑、关闭前保存、主子任务菜单归属、搜索、完成分组和快捷键。
- 同一测试项目运行 `tests/ui-draft-recovery.playwright.js` 通过：真实版本冲突、字段级重试、注入保存失败后切换宿主会话、返回任务恢复草稿并清理已保存草稿。
- 额外实测自动保存未完成时创建子任务、导出最新备注、日期/优先级/象限即时保存、逾期提示、看板和矩阵切换。
- 窄看板实测父子标题各高 40px，正文宽分别为 83px/79px/79px，避免了此前逐字排列；卡片无横向溢出。
- 深色以系统媒体模拟并设置文档 color-scheme 实际渲染检查；本轮未测试宿主主题设置菜单。
- 最终全新浏览器会话控制台：0 错误、0 警告。

这属于定向体验回归，不替代完整发布验收。旧报告的历史截图和行号不代表当前实现；原有两项草稿 P1 缺陷已在上述场景定向修复。

## 重跑浏览器回归

先在独立临时 DSH_HOME 安装并启动插件，用 Playwright 打开已认证的 DSH 中文任务管理页面。两个脚本会创建唯一名称的测试项目，并模拟一次保存失败，只用于测试 Profile。以仓库根目录为当前目录，在同一个浏览器会话和测试项目依次执行：

```sh
playwright-cli -s=task-ui run-code --filename=plugins/task-manager/tests/ui-workflows.playwright.js
playwright-cli -s=task-ui run-code --filename=plugins/task-manager/tests/ui-draft-recovery.playwright.js
```

会话 `task-ui` 须先连接上述临时 DSH 页面；第二个脚本依赖第一个脚本创建并选中的项目。任务标题可与其他项目重复，断言按项目 ID 区分。测试项目保留在临时数据库中，方便查看与截图。
