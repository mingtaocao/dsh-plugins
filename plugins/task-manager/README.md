# Task Manager（规划中）

目标：为个人同时推进多个独立项目提供简洁任务管理和优先级视图。

## 已确定功能

- 多项目、任务、任务状态、任务详情、子任务。
- 看板视图：按状态组织和推进任务。
- 艾森豪威尔四象限矩阵：按重要/紧急属性分类。
- 新任务默认 `important=false`、`urgent=false`，即「不重要、不紧急」，无「未分类」象限。

## 明确不做

- 跨项目「今日任务」汇总。
- Backlog 任务池。
- 任务计时。
- 周期任务。

## 仍需确认

- DSH 插件 API、页面扩展能力、数据存储方式。
- 看板/矩阵操作的交互细则，以及子任务与主任务状态的一致性。
- 数据迁移、失败恢复和宿主 UI 验收。

当前是需求入口，并非完整需求文档或可安装插件。开发前依照 [开发规范](../../docs/DEVELOPMENT.md) 补齐详细需求与验收用例。
